#### D28 の扱い

**この8項目は内部の記録である。そのままサイトに列挙しない。** 公開するのは次の2点だけ。

1. 月曜から木曜は店頭に立たない
2. その日々が、仕入れと加工にあてられている

残りは書かない理由がそれぞれある。

- **休暇** ... 公開すると「休んでいる日がある」ことが情報として立ってしまう。休息は当然の権利であり、店の案内に載せる性質のものではない
- **出張・業者WEB支援** ... 魚を買いに来た客には関係がない。指導の仕事は、お問い合わせページの「目利きの指導」が受け皿になっている
- **EC販売** ... 発送に触れない方針（Q17）と衝突する。範囲が確定するまで書かない

**平日に返信が来ることを約束しない。** 出張と休暇が月曜から木曜に入る以上、「平日もお返事します」と書けば守れない週が出る。
返信の速さを約束する文言を、どのページにも置かないこと。

本文は次のように書く。**この3行が正である。**

```
店頭は金・土・日。朝8時から15時まで。
月曜から木曜は、仕入れと加工にあてています。店頭には立ちません。
ご予約でのご注文を承ります。
```

**「月曜から木曜は店頭に立たない」旨を必ず添える。** これを書かないと、平日に来た客が閉まった店の前に立つ。
**「定休日」という語は使わない。** 休んでいるのではなく、仕入れと加工にあてている。この店ではそこが違う。
週の半分を仕入れと加工にあてていることは、隠す情報ではなく、この店がなぜ良い魚を持っているかの説明そのものである。

構造化データは完全な形で出せる。

```json
"openingHoursSpecification": [
  {
    "@type": "OpeningHoursSpecification",
    "dayOfWeek": ["Friday", "Saturday", "Sunday"],
    "opens": "08:00",
    "closes": "15:00"
  }
]
```

サイト本文・構造化データ・Googleビジネスプロフィールの**3箇所で完全に一致させる。** 1箇所だけ直さない。
