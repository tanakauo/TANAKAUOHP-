トップページを置き換えるものではない。トップページ v2.0 §0 で破棄した指定はこのページでも破棄する。

### 0-2｜破棄ではなく保留にするもの

**旧原稿パック v1.0 の「Smaregi 連携のEC導線」は、破棄も採用もしない。保留する。**
設計原本は固定費の低さを理由に Square を優先し、スマレジは固定費が高いとして除外している。旧原稿パックの記述はこれと食い違う。
どちらが現時点の判断なのかを本書では決めない。§11 に選択肢として整理し、§12-14 で確認する。**実装者はどちらのサービス名もページに書かない。**

## 1｜禁止事項（厳守）

1. **金茶・金色を一切使わない**
2. 黒地または紺地 × 金 × 明朝 の組み合わせを使わない
3. 写真の上に文字を重ねない（縦書き・横書きとも）
4. 見出しの上に小さな英字ラベル（`THE TIDE` `ABOUT` `NEWS` 等）を置かない
5. 中央揃えの大見出しを連発しない。本文・見出しは左揃えを基本とする
6. 同じ「画像＋文字の左右割り」を3つ以上連続させない
7. 角丸カードの多用、カード左端のアクセントバーを使わない
8. em ダッシュ（U+2014）および en ダッシュ（U+2013）を一切使わない。区切りが要るときは半角ハイフン（U+002D）または読点を使う
9. 絵文字を見出し記号に使わない
10. AI合成画像を使わない。写真は実写のみ
11. **一海（畑地優二）とのアライアンスに一切触れない**（田中氏指示 2026-07-06。デザイン・コピー・提案いずれも対象外）
12. 法人（有限会社タナカ／SAKANA TANAKA）に言及しない。主語は田中雄一郎個人

### 1-2｜本ページ固有の禁止

13. **価格・金額の数字を書かない。** 日々変わる商材であり、載せない方針が確定している（`docs/open-questions.md` D1）
14. **「〜円から」「時価」「応相談」「参考価格」「税込」「送料無料」も書かない。** 代わりに `確認中` と書くこともしない。**価格の欄そのものを作らない**
15. **商品を等幅3カラムのカードで並べない。** `repeat(3, 1fr)` の商品グリッド、角丸カード、影付きタイル、ホバーで浮くカードを実装しない。§4-3 の台帳組みで組む
16. 品目名・魚種を推測で書かない。実際に扱っている確証のない魚種名を1つも置かない
17. 内容量、重量、賞味期限、消費期限、保存温度、産地の断定を書かない。食品表示は確定情報でしか出せない（§11-4）
18. カート、決済ボタン、購入数の入力欄、在庫数の表示を実装しない。方式が未確定である（§11）
19. 「絶品」「至福」「贅沢」「究極」「厳選」式の形容を使わない。本人の文体は短い平叙文
20. 鯛塩ラーメンを購入できるものとして書かない。開発中である。予約を受け付ける文言を置かない
21. 在庫を「残りわずか」「完売間近」等の煽りで書かない。数字も書かない
22. **会員制度を募集として書かない。** 店頭で接客した顧客へ案内する制度であり、一般公募ではない（`docs/open-questions.md` D32）
23. **不定期魚BOXを書かない。** 会員への優先アクセスが前提である（同 D33）
24. **EC・通販・お取り寄せの導線を作らない。** 初年度の店頭外売上は 0 で計画されている（同 D34）
25. 事業計画書の数値（売上、客単価、原価率、来店客数、返済計画）を1つも書かない。社内・金融機関向けの文書である

## 2｜書体

トップページ v2.0 §2 と同一。変更しない。

```css
--mark: "Helvetica Neue", Helvetica, Arial, sans-serif;
--jp: "Helvetica Neue", Helvetica, Arial,
      "Yu Gothic Medium", "游ゴシック Medium", YuGothic,
      "Hiragino Kaku Gothic ProN", "Noto Sans JP", sans-serif;

.wordmark      { font-family: var(--mark); font-weight: 300;
                 letter-spacing: .06em; line-height: 1; }
.wordmark-sub  { font-family: var(--mark); font-weight: 300;
                 letter-spacing: .14em; }   /* by YUICHIRO TANAKA */
```

- ヘッダー・フッターのワードマークはロックアップ A（横組み・左揃え）
- 正方形の UO アイコンは使わない
- 数字が和文の全角字形で出ることを禁じる。実装後にスクリーンショットで必ず確認する
- 電話番号、更新日、手順の番号は `font-variant-numeric: lining-nums tabular-nums`
- Web フォントの読み込みは不要

### 2-2｜このページの前提

**価格が日々変わる商材である。** 同じ魚種でも日によって値が違う。
したがって、価格をページに固定値で持たせる設計にしない。これは未確定だから書かないのではない。**確定しても書かない。**
**この点は決着している。価格は載せない**（`docs/open-questions.md` D1）。実装は「価格の行を後から差し込めるが、いま置いていない」形にする（§9-3）。

## 3｜配色

トップページ v2.0 §3 と同一トークン。新しい色を足さない。
**「売り」を示す赤、在庫を示す緑や橙、バッジの色を導入してはならない。** 状態は文字で書く。色で意味を持たせない（色覚に依存する表現を作らない）。

```css
:root{
  --paper:#e8e2d4;                    /* 麻色。地 */
  --ink:#0d1f33;                      /* 深紺。文字 */
  --ink-70:rgba(13,31,51,.78);        /* 本文 */
  --ink-45:rgba(13,31,51,.66);        /* 注記・小ラベル */
  --rule:rgba(13,31,51,.16);          /* 罫 */
  --rule-strong:rgba(13,31,51,.30);   /* 強い罫 */
}

@media (prefers-color-scheme: dark){
  :root:not([data-theme="light"]){
    --paper:#0d1f33; --ink:#e8e2d4;
    --ink-70:rgba(232,226,212,.76); --ink-45:rgba(232,226,212,.58);
    --rule:rgba(232,226,212,.17); --rule-strong:rgba(232,226,212,.32);
  }
}
```

`[data-theme="dark"]` と `[data-theme="light"]` にも同じトークンを定義し、手動切替が両方向で効くようにする。
すべての文字が WCAG AA（本文 4.5:1）を満たすこと。薄灰 `#6b6b6b` は文字色に使わない（罫のみ）。

## 4｜ページの役割・導線・構成

### 4-0｜このページの役割

**このページは売り場ではない。相談の入口である。**
魚を選んで決済させるページではなく、「何を頼めるのかがわかり、電話かメールに進める」ページとして設計する。
価格・在庫・決済が未確定であること（§12）と、商材が日替わりであること（§2-2）から、この役割以外に置きようがない。方式が決まれば §11 の手順で足す。

### 4-1｜導線設計

`docs/seo-and-weekly-operations.md` §3 の内部リンク表に従う。**同じ意図のボタンを1ページに2つ置かない。**

| 入口 | 行き先 | 文言 | 形 |
|---|---|---|---|
| トップ「販売」 | このページ | 商品を見る | テキストリンク |
| このページ末尾（§4-9） | ご予約・お問い合わせ | ご予約・お問い合わせ | **ボタン。ページ中これ1つだけ** |
| このページ §4-10 | トップページ | トップへ戻る | テキストリンク |

**ボタンは §4-9 の1つだけとする。見出し部にボタンを置かない。**
浜焼きページは見出し部にボタンを置いているが、あちらは短い1枚ものである。このページは読ませてから押させる長さになる。
先頭と末尾に同じ「ご予約・お問い合わせ」を置くと、SEO手順書 §8-5 の「同じ意図のCTAが1ページに重複していない」に反する。

**個々の商品行に「この品を問い合わせる」式のリンクを置かない。** 同じ意図のCTAが行数だけ増える。問い合わせ先は1つに集約する。
「カートに入れる」「今すぐ購入」も置かない（禁止事項18）。

### 4-2｜セクション構成

レイアウトの型を4種類以上使い分ける。同じ型を連続させない。**写真は使わない**（§5）。型と余白と罫だけで持たせる。

| # | セクション | レイアウトの型 |
|---|---|---|
| 1 | 見出し部 | 文字のみ・左揃え。写真を敷かない |
| 2 | 値段のこと | 非対称の2段組み（左に見出し、右に本文）。テキストのみ |
| 3 | 扱っているもの | 横罫の台帳組み。1件1行群。**カードにしない。3カラムに割らない**（5件） |
| 4 | いま作っているもの | 上下を罫で挟んだ短い一段。ページ中1回だけ |
| 5 | 帯 | 深紺の全幅帯。ページ中 **1回だけ** |
| 6 | 今週の魚 | 罫だけの定義リスト。カード化しない。**週次で書き替える唯一の場所** |
| 7 | ご注文からお渡しまで | 数字を左にぶら下げた縦の4段。横並びの3ステップにしない |
| 8 | お届けとお支払い | 罫だけの定義リスト |
| 9 | 末尾 | 段落1つ ＋ ボタン1つ |
| 10 | 場所と連絡 | 3列 |

定義リストの型は §6 と §8 で2回使うが、あいだに §7 が入るので連続しない。

## 5｜素材

### 5-1｜このページの写真は無い

### 10-1｜設計の核
