# 公開中サイトの止血手順

`www.tanakauo.com` に、田中氏が承諾していない内容が現在も公開されている（`docs/open-questions.md` §0）。
**WordPress版を作り終えるのを待たず、先に消す。** 消すのは3箇所だけである。サイトごと消す必要は無い。

**サイトを削除しないこと。** このWordPress + SWELL はそのまま作り直しに使う。中身だけを抜く。

| 項目 | 値 |
|---|---|
| ログインURL | `https://tanakauo.com/login_89957` |
| ユーザー名 | `yuichirotanaka` |

**`wp-login.php` では入れない。** SiteGuard WP Plugin がログインURLを変更している。上のURLを使う。

パスワードが分からなければ、そのページの「パスワードをお忘れですか？」から再設定する。
再設定用のメールは `tanakauojapan@gmail.com` に届く。

## 1｜消す3箇所（この順で）

### ① 一海とのアライアンス節 ... **最優先**

見出しは `ALLIANCE`。本文は次のとおり。

```
TANAKA UOは、一海（いちかい）と補完型アライアンスを組む。
魚を届ける構造と、魚を活かすレシピ・文脈の双方を接続し、価格の川下まで設計する。
```

**節ごと消す。** 文言を書き換えるのではなく、ブロックごと削除する。
「一海」「いちかい」「畑地」の文字が1つも残らないようにする。

### ② 法人名を含む沿革

```
創業100年のタナカ鮮魚店（有限会社タナカ）の4代目を承継し、TANAKA SAKANAに改称。
新たにTANAKA UOを立ち上げ。
```

**この一文ごと消す。** 主語は田中雄一郎個人である。経歴を残したい場合は、
`docs/open-questions.md` D35 の書き方（17歳から父の割烹料亭で働き、久留米市内の飲食業を起点に独立、40歳で柳川へ帰郷）に差し替える。
ただし**今は消すだけでよい。** 書き足すのは作り直しのときでよい。

### ③ 住所の番地

```
福岡県柳川市大和町中島883-1
```

**番地を消し、「福岡県柳川市」までにする。**
883-1（事業所）と 884（対面営業場所）のどちらが客の行く先か未確定である（同 Q26）。
誤った番地は、番地が無いことより悪い。地図アプリが別の建物を指す。

## 2｜探し方と消し方

1. 管理画面に入り、左メニューの「固定ページ」を開く。トップに使われているページを開く
   （どれか分からなければ「設定」→「表示設定」でホームページに指定されているページを見る）
2. ブロックエディタが開いたら、上の3つの文言を目で探す。`ALLIANCE` は見出しなので見つけやすい
3. 消したいブロックをクリックして選び、右上の「⋮」から**「削除」**を選ぶ
4. 右上の**「更新」**を押す

**うまく見つからないときは、ページごと下書きに戻してよい。**
ページ右側の「表示状態」または「公開状態」を「下書き」に切り替えて「更新」を押す。
中身が外から見えなくなる。作り直しのときに戻せる。**これが一番確実で、迷ったらこれでよい。**

## 3｜消したあとの確認

キャッシュが残っていると、消したのに古い内容が見えることがある。

1. ConoHa WING の管理画面で「サイト管理」→「サイト設定」→ コンテンツキャッシュをクリアする
2. SWELL 側にキャッシュ設定があればそれもクリアする
3. スマホで**シークレットウィンドウ**を開き、`https://www.tanakauo.com` を表示する
4. ページ内検索で次の語を探し、**すべて0件**であることを確かめる

```
一海
畑地
有限会社
TANAKA SAKANA
883
```

`www` の有無で別のページが出ることがあるので、`https://tanakauo.com` でも同じ確認をする。

## 4｜今回は触らないもの

急がなくてよい。作り直しのときにまとめて直す。

- 黒地に金茶のデザイン、`DISTRIBUTION` `VALUE` 等の小英字ラベル、水温・波高のウィジェット、ネットワーク図
- 銀行振込・キャッシュレス・「注文日から3日以内」の発送・定期便の記述（現行方針 D34 と衝突するが、承諾違反ではない）
- 営業時間の表記

**これらは間違ってはいても、外に出て困る性質のものではない。** 上の3箇所とは扱いを分ける。
