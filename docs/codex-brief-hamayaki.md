# Codex実装指示書 - TANAKA UO 浜焼きページ v1.0

発行：2026-08-13／田中雄一郎
用途：Codex への実装依頼。トップページ指示書 v2.0（`docs/codex-implementation-brief.md`）の下位文書。
書体・配色・禁止事項は v2.0 を継承する。本書はそれに反する指定を一切含まない。

## 0｜位置づけと破棄

このページはトップページの「魚の仕事」内「販売：浜焼きはその場で炭にかけます。」を受ける下層ページである。
トップページを置き換えるものではない。トップページ v2.0 §0 で破棄した指定はこのページでも破棄する。

| 破棄する指定 | 理由 |
|---|---|
| 装飾色 金茶 `#B0894E` | 深紺・黒地に金は生成AIの既定表現 |
| 和文 Noto Serif JP の全面使用 | 同上。明朝一色は避ける |
| 写真に重ねる縦書きコピー | 同上 |
| 薄暮ダーク基調のヒーロー | 同上 |
| 小英字ラベル（`HAMAYAKI` `MENU` `ACCESS` 等） | 見出しごとの英字ラベルは生成AIの既定表現 |
| トップページの `Eat Fresh Fish.` 帯の再掲 | 同じ文言を2ページで繰り返さない。§4-6 の和文一行に差し替える |

## 1｜禁止事項（厳守）

1. **金茶・金色を一切使わない**
2. 黒地または紺地 × 金 × 明朝 の組み合わせを使わない
3. 写真の上に文字を重ねない（縦書き・横書きとも）
4. 見出しの上に小さな英字ラベル（`THE TIDE` `ABOUT` `NEWS` 等）を置かない
5. 中央揃えの大見出しを連発しない。本文・見出しは左揃えを基本とする
6. 同じ「画像＋文字の左右割り」を3つ以上連続させない
7. 角丸カードの多用、カード左端のアクセントバーを使わない
8. em ダッシュ `—` および en ダッシュ `–` を一切使わない。ハイフン `-` を使う
9. 絵文字を見出し記号に使わない
10. AI合成画像を使わない。写真は実写のみ
11. **一海（畑地優二）とのアライアンスに一切触れない**（田中氏指示 2026-07-06。デザイン・コピー・提案いずれも対象外）
12. 法人（有限会社タナカ／SAKANA TANAKA）に言及しない。主語は田中雄一郎個人

### 1-2｜本ページ固有の禁止

13. **価格・金額の数字を書かない。** 未確定である。`確認中` と組む（§9）
14. 品目名を推測で書かない。写真に写っているものも、確定するまで品書きに載せない
15. 「絶品」「至福」「贅沢」式の形容を使わない。本人の文体は短い平叙文
16. 予約フォーム・カート・決済ボタンを実装しない。導線は電話とメールのみ

--jp: "Helvetica Neue", Helvetica, Arial,
      "Yu Gothic Medium", "游ゴシック Medium", YuGothic,

## 3｜配色

トップページ v2.0 §3 と同一トークン。新しい色を足さない。**炭火の写真に合わせて赤やオレンジのアクセント色を導入してはならない。** 火の色は写真の中だけにある。

```css
:root{
  --paper:#e8e2d4;                    /* 麻色。地 */
  --ink:#0d1f33;                      /* 深紺。文字 */
  --ink-70:rgba(13,31,51,.78);        /* 本文 */
  --ink-45:rgba(13,31,51,.66);        /* 注記・小ラベル */
  --rule:rgba(13,31,51,.16);          /* 罫 */
  --rule-strong:rgba(13,31,51,.30);   /* 強い罫 */
}

@media (prefers-color-scheme: dark){
  :root:not([data-theme="light"]){
    --paper:#0d1f33; --ink:#e8e2d4;
    --ink-70:rgba(232,226,212,.76); --ink-45:rgba(232,226,212,.58);
    --rule:rgba(232,226,212,.17); --rule-strong:rgba(232,226,212,.32);
  }
}
```

`[data-theme="dark"]` と `[data-theme="light"]` にも同じトークンを定義し、手動切替が両方向で効くようにする。
すべての文字が WCAG AA（本文 4.5:1）を満たすこと。薄灰 `#6b6b6b` は文字色に使わない（罫のみ）。

## 4｜ページ構成

レイアウトの型を4種類以上使い分ける。同じ型を連続させない。
**画像＋文字の左右割りはページ中 1回だけ**（写真が3点しかないため、繰り返すと型が痩せる）。

| # | セクション | レイアウトの型 | 写真 |
|---|---|---|---|
| 1 | 見出し部 | 文字のみ・左揃え。写真を敷かない | なし |
| 2 | 焼く場所 | 全幅の写真 1点 ＋ 下にキャプション1行 | `mise.jpg` |
| 3 | 火のこと | 画像＋文字の左右割り（写真左・文章右）。ページ中1回だけ | `sumibi.jpg` |
| 4 | 品書き | 罫組の一覧。価格は未確定の枠（§9） | なし |
| 5 | 帯 | 深紺の全幅帯。ページ中 **1回だけ** | なし |
| 6 | ご利用 | 罫だけの定義リスト。カード化しない | なし |
| 7 | 焼かずに持ち帰る | 写真 → 長文 | `nodoguro.jpg` |
| 8 | 場所と連絡 | 3列 | なし |

**セクション2と3で写真が連続する。** 2は全幅・横位置、3は本文幅内・縦位置の左右割りなので型は異なる。それ以上写真を近接させない。

### 5-1｜必ず対処すること：ミュートアイコンの写り込み

**3点とも動画からの静止画で、右下に消音（スピーカー）アイコンが焼き込まれている。** そのまま出すと素人仕事に見える。

暫定対処として CSS で下端を切る。切る量は次のとおり。

| ファイル | 切る量 | 切った後の見え方 |
|---|---|---|
| `mise.jpg` | 下端 13% | 手前の網の最前列がわずかに減る。全景は保たれる |
| `sumibi.jpg` | 下端 8% | 網の手前側が減る。炎と魚は残る |
| `nodoguro.jpg` | 下端 8% | 手前の開きの尾が切れる。列は保たれる |

```css
.photo{ overflow:hidden; }
.photo img{ display:block; width:100%; height:auto; }
/* 下端を切る。値は上表 */
.photo--mise img    { margin-bottom:-13%; }
.photo--sumibi img  { margin-bottom:-8%;  }
.photo--nodoguro img{ margin-bottom:-8%;  }
```

`object-fit: cover` と固定 `aspect-ratio` で切ってもよい。いずれの方法でも、**実装後にスクリーンショットでアイコンが消えていることを目視で確認する**（§11-4）。
恒久対処は元素材の差し替えである。§10-11 で依頼している。

### 5-2｜解像度の上限

3点とも動画由来で解像度が低い。**実寸を超えて引き伸ばさない。**

- `mise.jpg`：全幅で使うが、本文の最大幅 1180px を超えて広げない。実寸 1206px でちょうど足りる
- `sumibi.jpg`：左右割りの片側。表示幅 **560px 以下**に収める
- `nodoguro.jpg`：全幅にしない。表示幅 **760px 以下**、左揃えで置く。右の余白は空けたままにする
- すべて `loading="lazy"`（§4-2 の1点目のみ `loading="eager"`）と `width` `height` 属性を付け、レイアウトシフトを防ぐ

### 5-3｜トップページとの重複

`sumibi.jpg` と `nodoguro.jpg` は、トップページ v2.0 §5 で「魚の仕事」の写真2枚並びにも割り当てられている。
同じ2点が2ページに出ることになる。次のいずれかで処理する。判断は §10-12 で確認する。

1. この2点は浜焼きページを主とし、トップページ側は別カットに差し替える（推奨）
2. 両方に出す。ただしトリミングを変える（トップは横位置に切る、本ページは縦のまま）

決まるまでは 2 の方針で実装してよい。トップページ側のファイルは編集しない。

### 5-4｜alt テキスト

装飾ではなく内容なので、すべてに書く。文中の見出しをそのまま繰り返さない。

```
mise.jpg     alt="店先の浜焼き台と、奥の屋外席"
sumibi.jpg   alt="網の下から立ち上がる炎と、網の上の開いた魚"
nodoguro.jpg alt="焼き台の金網に並べた干物"
```

## 6｜レスポンシブ

- 余白：`clamp(20px, 5vw, 64px)`
- 最大幅：`1180px`
- 多列グリッドは 820px 以下で1列に落とす
- §4-3 の左右割りは 820px 以下で「写真 → 文章」の縦積みにする
- §4-8 の3列は 820px 以下で1列
- ヒーロー高さに `h-screen` を使わない。`min-h-[100dvh]` または `clamp()` を使う
- 375px 幅で横スクロールが出ないこと
- 品書きの罫組は 375px でも折り返さずに読めること。折り返すなら品目名を上、価格を下の2行組にする

## 7｜動き

抑制する。CSS の `:hover` と `:focus-visible` のみ。
スクロール連動アニメーション、パララックス、無限ループ、炎の揺らぎ演出、`filter` によるちらつきは実装しない。
`window.addEventListener('scroll', ...)` を使わない。

## 8｜メタ情報

```html
<title>浜焼き｜TANAKA UO</title>
<meta name="description" content="柳川の店先で、仕入れた魚をその日のうちに炭にかけます。">
<link rel="canonical" href="https://www.tanakauo.com/hamayaki/">
```

- 構造化データ（JSON-LD）は入れてよいが、**`openingHours` `priceRange` `menu` は書かない。** 未確定の値を機械可読で出すと誤情報になる
- `h1` はページに1つ。§4-1 の「浜焼き」
- OGP 画像は `images/mise.jpg`。ただし §5-1 のトリミング済みファイルを別途書き出してから指定する。未書き出しの間は OGP 画像を指定しない

## 9｜未確定の品書きと価格の扱い

価格・品目は確定していない。**仮の数字を1つも書かない。** 枠だけを先に組み、確定後に文字を流し込めるようにする。

### 9-2｜守ること

- 行は **6行**用意する。増減は確定後に行う
- 品目名の欄に、写真から読み取れる魚種や貝の名を先回りして書かない

- セットや人数あたりの単価という組み方が要るかどうかも未確定である。1品1行の素直な組みにしておく
- カード化しない。罫だけで組む（禁止事項7）
- `確認中` の文字は `--ink-45` で組む。地に沈めない
