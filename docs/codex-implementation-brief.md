## 1｜禁止事項（厳守）

1. **金茶・金色を一切使わない**
2. 黒地または紺地 × 金 × 明朝 の組み合わせを使わない
3. 写真の上に文字を重ねない（縦書き・横書きとも）
4. 見出しの上に小さな英字ラベル（`THE TIDE` `ABOUT` `NEWS` 等）を置かない
5. 中央揃えの大見出しを連発しない。本文・見出しは左揃えを基本とする
6. 同じ「画像＋文字の左右割り」を3つ以上連続させない
7. 角丸カードの多用、カード左端のアクセントバーを使わない
8. em ダッシュ（U+2014）および en ダッシュ（U+2013）を一切使わない。区切りが要るときは半角ハイフン（U+002D）または読点を使う
9. 絵文字を見出し記号に使わない
10. AI合成画像を使わない。写真は実写のみ
11. **一海（畑地優二）とのアライアンスに一切触れない**（田中氏指示 2026-07-06。デザイン・コピー・提案いずれも対象外）

## 2｜書体

### ワードマーク「TANAKA UO」
公式ロゴタイプ（`tanakauo_logotype_1.html`）に厳密に従う。画像は使わず活字で組む。

```css
--mark: "Helvetica Neue", Helvetica, Arial, sans-serif;

.wordmark      { font-family: var(--mark); font-weight: 300;
                 letter-spacing: .06em; line-height: 1; }
.wordmark-sub  { font-family: var(--mark); font-weight: 300;
                 letter-spacing: .14em; }   /* by YUICHIRO TANAKA */
```

- 組み方はロックアップ **A（横組み・左揃え）** をヘッダー・フッターとも使用する
- サブは主の約 1/3 の級数、上に 6px 程度のアキ

### UO 記号型（ロックアップ C）

`UO` を大きく、その下に `TANAKA` を **`UO` の右端で揃えて**小さく置く型。公式に存在する正式なバリエーションで、タグ・シール・ファビコン・SNSのアイコンに使う。

```css
.uo-mark   { font-family: var(--mark); font-weight: 300;
             font-size: 150px; line-height: 1; letter-spacing: 0; }
.uo-tanaka { font-family: var(--mark); font-weight: 300;
             letter-spacing: .3em; }   /* TANAKA。UO の右端で揃える */
```

**ページ本文では使わない。** ヘッダーとフッターはロックアップ A に統一する。混在させない。

### 標語

```
一貫不動
魚の選定、加工、販売、発信を一貫して行う。
```

この2行は必ず組にして使う。片方だけを単独で置かない。置き場所は署名部（§4-9）とする。

### 本文・見出し
欧文を font-family の先頭に置く。**数字と英字は欧文が受け持ち、かな漢字だけが後続の和文ゴシックに落ちる。**

```css
--jp: "Helvetica Neue", Helvetica, Arial,
      "Yu Gothic Medium", "游ゴシック Medium", YuGothic,
      "Hiragino Kaku Gothic ProN", "Noto Sans JP", sans-serif;
```

- 数字が和文の全角字形で出ることを禁じる。実装後にスクリーンショットで必ず確認する
- 数字が縦に揃う箇所は `font-variant-numeric: lining-nums tabular-nums`
- Web フォントの読み込みは不要。システムフォントで完結させる

## 3｜配色

```css
:root{
  --paper:#e8e2d4;                    /* 麻色。地 */
  --ink:#0d1f33;                      /* 深紺。文字 */
  --ink-70:rgba(13,31,51,.78);        /* 本文 */
  --ink-45:rgba(13,31,51,.66);        /* 注記・小ラベル */
  --rule:rgba(13,31,51,.16);          /* 罫 */
  --rule-strong:rgba(13,31,51,.30);   /* 強い罫 */
}
```

ダークは紙と墨を反転する。地 `#0d1f33`／文字 `#e8e2d4`。

```css
@media (prefers-color-scheme: dark){
  :root:not([data-theme="light"]){
    --paper:#0d1f33; --ink:#e8e2d4;
    --ink-70:rgba(232,226,212,.76); --ink-45:rgba(232,226,212,.58);
    --rule:rgba(232,226,212,.17); --rule-strong:rgba(232,226,212,.32);
  }
}
```

`[data-theme="dark"]` と `[data-theme="light"]` にも同じトークンを定義し、手動切替が両方向で効くようにする。

**コントラスト要件：** すべての文字が WCAG AA（本文 4.5:1）を満たすこと。上記の透過率は実測で 4.78:1 以上を確認済み。値を薄くしない。薄灰 `#6b6b6b` は麻色地で 4.13:1 と不足するため、**文字色には使わない**（罫のみ）。

### 5-2｜画像生成の共通指定

生成AIで画像を作る場合、次の指定を必ず含める。用途別の指定は共通指定に足して使う。

**共通（すべての生成に付ける）**
```
不要な要素は削除し、影は柔らかく自然に調整。
彩度は上げすぎず、落ち着いた自然なトーンで高品質に仕上げてください。
ホワイトバランスは約5500Kの自然光を基準に、色かぶりや黄ばみを抑え、
自然で違和感のない色味に仕上げてください。
```

**写実で撮る場合**
```
[被写体]を写実的で描き、50mmレンズ・F1.8相当の浅い被写界深度、
背景は自然にぼかし、4K品質で生成してください。
```

**イラストで描く場合**
```
[被写体]をイラスト風で描き、50mmレンズ・F1.8相当の浅い被写界深度、
背景は自然にぼかし、4K品質で生成してください。
```

**プレゼン資料の挿絵に使う場合**
```
プレゼン資料の挿絵として使用するため、背景はシンプルな単色または
グラデーションにし、不要な装飾や文字、小物は入れないでください。
```

**SNS投稿のサムネイルに使う場合**
```
SNS投稿のサムネイルとして使うので、文字を配置できる余白を上下どちらかに確保し、
被写体は中央から少し外して配置してください。
```

店主のアニメ調プロフィールは「共通」＋「イラストで描く場合」を使う。柔らかく親しみのある絵柄とし、リアル寄せはしない。背景は麻色 `#e8e2d4` に馴染む無地とする。

## 6｜レスポンシブ

- 余白：`clamp(20px, 5vw, 64px)`
- 最大幅：`1180px`
- 多列グリッドは 820px 以下で1列に落とす
- ヒーロー高さに `h-screen` を使わない。`min-h-[100dvh]` または `clamp()` を使う
- 375px 幅で横スクロールが出ないこと

## 7｜動き

抑制する。CSS の `:hover` と `:focus-visible` のみ。スクロール連動アニメーション、パララックス、無限ループは実装しない。`window.addEventListener('scroll', ...)` を使わない。

## 8｜検証（実装後に機械的に照合する）

```
1. U+2014 と U+2013 の出現数が 0（`grep -P "[\x{2013}\x{2014}]"` で確認）
2. grep で金茶系（#b0〜#bc 台の暖色）の出現数が 0
3. 小英字ラベル（uppercase + letter-spacing の小見出し）の出現数が 0
4. writing-mode / rotate( の出現数が 0
5. 画像＋文字の左右割りが3連続していない
6. text-align:center が本文・見出しに使われていない
7. ライト／ダーク両モードで描画し目視
8. 375px で横スクロールが出ない
9. 数字が欧文フォントで出ている（スクリーンショットで目視）
10. 全文字のコントラストが WCAG AA 以上
11. "一海" "畑地" "有限会社タナカ" "SAKANA TANAKA" の出現数が 0
```

## 9｜納品

`index.html` 単体（外部依存なし。Web フォント読み込みなし）。画像と映像は相対パス参照。
WordPress + SWELL への移植を前提とするため、フレームワークを挟まない素の HTML と CSS で書くこと。
