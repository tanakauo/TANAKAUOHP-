# TANAKAUOHP-
WordPressとSWELLを使用してTANAKA UOのHPを作成する。

## HP 3案プロトタイプ

Obsidian「TANAKA UO 設計原本.md」・事業計画書・HP週次更新チェックリストを基に作成した静的プロトタイプ。
いずれも WordPress + SWELL への移植を前提とする(単一HTML・外部依存はGoogle Fontsのみ)。

| 案 | ファイル | コンセプト |
|---|---|---|
| A | [`site-a/index.html`](site-a/index.html) | 和モダン・思想型(ROOTED, STILL MOVING を正面に) |
| B | [`site-b/index.html`](site-b/index.html) | 店舗・旬魚EC型(週次更新チェックリスト準拠) |
| C | [`site-c/index.html`](site-c/index.html) | 事業・B2B型(4本柱・市場ネットワーク) |

- 3案比較トップ: [`index.html`](index.html)
- 要件の棚卸し: [`docs/hp-requirements-checklist.md`](docs/hp-requirements-checklist.md)
